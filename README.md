# CUPickleBall-Website
CU Pickleball Club — Carroll University Pickleball Club website for schedules, events, match sign-ups, club information, and member resources.

CU Pickleball Club 🏓

A website designed for the Carroll University Pickleball Club to help students discover the club, stay informed about meetings and events, sign up for matches, and connect with other members.

📖 About the Project

The Carroll University Pickleball Club has had difficulty keeping members informed about when and where pickleball meetings take place. This project aims to create a centralized and dynamic website where students can easily find club information, upcoming events, meeting schedules, and opportunities to play.

The website is designed to be more interactive and useful than a traditional campus group page. It will provide students with a simple way to learn about pickleball, join the club, sign up for matches, and stay connected with the club.

🎯 Target Audience

The primary users of this website are:

Carroll University students interested in pickleball

Current pickleball club members

Students interested in joining the club

Players looking for opportunities to play with other members

The website will allow students to quickly find the next club meeting while giving current members additional tools for organizing matches and practices.

✨ Features
1. About the Club

Learn more about the Carroll University Pickleball Club, including:

Club description

Executive board

Club goals

General information about joining

2. Match & Practice Sign-Up

Members will be able to sign up for matches or practices with other club members.

This feature is intended to help:

Organize players

Reduce waiting times

Manage court availability

Make it easier for members to find people to play with

3. Email Sign-Up

Students can join the club's email chain to receive information about:

Upcoming events

Club meetings

Tournaments

Announcements

Other pickleball-related activities

4. Upcoming Events & Schedule

A schedule/calendar will display important club activities, including:

Weekly meetings

Special events

Tournaments

Practices

Other club activities

5. How to Play Pickleball

A dedicated section will introduce students to the sport.

It may include:

Basic rules

Scoring

Court information

Equipment

Gameplay guidelines

This section is especially useful for students who have never played pickleball before.

6. Contact & Join

Students will be able to contact the club or request more information about joining.

7. Club Leaderboard

A leaderboard can highlight club tournament results and past winners.

8. Member Features

After signing in, members may have access to additional features such as:

Match and practice sign-ups

Upcoming events and schedules

Club leaderboard

Equipment requests

Booking courts and playing times

Equipment rentals

Opportunities to play outside of regular club meetings

♿ Accessibility & Usability

The website will be designed with usability and accessibility in mind.

Planned considerations include:

Responsive design so the website works on phones, tablets, and computers

Search functionality to help users quickly find information

Filters for schedules, events, and other information

Clear navigation between major sections

Simple forms for joining and signing up for matches

Readable text and appropriate color contrast

Mobile-friendly layouts and controls

🛠️ Technologies
HTML5

HTML will be used to create the structure and content of the website.

CSS

CSS will be used to create the visual design and layout.

Planned techniques include:

Flexbox

CSS Grid

Responsive design

Animations and transitions

JavaScript

JavaScript will provide interactive functionality, including:

Form interactions

Form validation

Search functionality

Filters

Dynamic content

Other interactive website features

JSON

JSON may be used to store information that does not need to come from a database, such as:

Club events

Meeting information

Leaderboard data

Other static club information

📌 Project Scope

The primary goal of this project is to create a website that helps the Carroll University Pickleball Club:

Increase student awareness of the club

Make meeting times and locations easier to find

Encourage students to join

Help members organize matches and practices

Provide information about pickleball

Create a centralized location for club information

🚀 Stretch Goals

If time allows, we would like to implement additional features.

Potential stretch goals include:

Allowing members to organize games outside of normal club meetings

Court and time reservations

Equipment rental requests

Member accounts

Tournament tracking

Interactive games created by our team

Making it easy for executive board members to update meetings and events

Additional dynamic content

⚠️ Potential Challenges

Some of the challenges we anticipate include:

Dynamic and Effective Design

Creating a website that looks visually appealing while remaining easy to navigate and use on different screen sizes.

Updating Club Information

We want to make it easy for the executive board to add or update meetings, events, and other club information.

Interactive Features

Implementing forms, search functionality, filters, and other JavaScript features while keeping the website simple for users.

Games

We may attempt to integrate games that our team has created into the website. This will depend on available development time and the complexity of the games.

🗺️ Future Development

As development continues, we plan to create a more detailed sitemap and wireframe after gaining a better understanding of the CSS and web-development techniques needed for the project.

The design will continue to evolve based on what we learn throughout development.
